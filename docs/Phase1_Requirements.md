# Phase 1 — Requirements and Planning

## Requirements
- Multi-organization project management
- Users, roles, orgs, teams, projects, issues

## Roles
- Admin
- OrgAdmin
- Manager
- Developer

## User Stories
- Register/login
- OrgAdmin can create orgs and invite users
- Manager can create projects and assign teams
- Developer can view and update issues

## MVP
- Backend APIs for auth, orgs, teams, projects, issues
- Angular app with login and basic CRUD
